## 三、P0 级 — 立即修复（高优先级）

### 问题1：【致命】security.js 使用 ES Module export，与项目 CommonJS 体系冲突
- **严重程度**：🔴 **高**
- **位置**：`miniprogram/utils/security.js:11,39,67,91`
- **归属**：📍 前端
- **触发场景**：所有涉及安全检测的页面加载时模块解析直接报错
- **影响范围**：
  - `miniprogram/pages/garden/diary-edit.js:4` — 日记编辑内容安全检测不可用
  - `miniprogram/pages/profile/settings/index.js:5` — 昵称/头像安全检测不可用
  - `miniprogram/pages/profile/feedback/index.js:3` — 反馈文本安全检测不可用
  - `miniprogram/pages/profile/index.js:5` — 登录头像安全检测不可用
- **根因**：`security.js` 全部使用 `export function` 语法，但4个引用文件均使用 `require()` 解构导入，微信小程序中两者不能混用
- **修复方案**：
```javascript
// security.js 改为 CommonJS 格式
const checkText = async (text) => { /* ... */ }
const checkImage = async (mediaUrl) => { /* ... */ }
const showSecurityWarning = (result, options = {}) => { /* ... */ }
const checkAll = async ({ text, images }) => { /* ... */ }
module.exports = { checkText, checkImage, showSecurityWarning, checkAll }
```

### 问题2：【致命】settings/index.js 存在重复 onLoad/onShow 方法定义
- **严重程度**：🔴 **高**
- **位置**：
  - 第一处：`miniprogram/pages/profile/settings/index.js:18-31`
  - 第二处：`miniprogram/pages/profile/settings/index.js:242-254`
- **归属**：📍 前端
- **触发场景**：JavaScript 对象字面量中同名键后者覆盖前者
- **影响**：
  - 第18行的 `onLoad` 被第242行覆盖 → `aboutMode` 始终由第二版逻辑控制
  - 第二版使用 `this._aboutMode` 但第一版 `onShow` 中引用 `!this._aboutMode`，变量初始化时机可能异常
  - "关于"页面模式可能失效或行为不一致
- **修复方案**：删除重复定义，合并为单一定义：
```javascript
onLoad(options) {
  this._aboutMode = !!(options && options.about)
  this.setData({ aboutMode: this._aboutMode })
  if (!this._aboutMode) {
    this.loadUser()
    this.calcCacheSize()
  }
},
onShow() {
  if (!this._aboutMode) {
    this.setData({ settings: settingsUtil.getAll() })
  }
},
```

### 问题3：【致命】diary 云函数缺少 update / detail action 注册
- **严重程度**：🔴 **高**
- **位置**：`cloudfunctions/diary/index.js` actions 路由表
- **归属**：📍 后端（云函数）
- **触发场景**：
  - 用户编辑已有日记保存时 → 前端调用 `action: 'update'` → 返回 `{ code: -1, message: '未知操作: update' }`
  - 日记编辑页加载已有日记时 → 前端调用 `action: 'detail'` → 同样报错
- **影响范围**：
  - 编辑日记功能**完全不可用** (`diary-edit.js:160`)
  - 加载已有日记进行编辑**完全不可用** (`diary-edit.js:53`)
- **修复方案**：在 diary 云函数 index.js 的 actions 对象中补全注册：
```javascript
const actions = {
  add: require('./actions/add'),
  list: require('./actions/list'),
  detail: require('./actions/detail'),   // ← 新增
  update: require('./actions/update'),   // ← 新增
  delete: require('./actions/delete'),
}
```

- **严重程度**：🟡 **中**
- **位置**：`miniprogram/pages/garden/plant-detail.js:266`
- **归属**：📍 前端

```javascript
if (typeof wx.showDatePicker === 'function') {

  wx.showToast({ title: '请升级微信以体验此功能', icon: 'none' })
}
```

  - `miniprogram/pages/garden/plant-detail.js:87-91` （loadDiary）
- **归属**：📍 前端
- **问题代码**：
```javascript
// 当前：串行等待每篇日记的图片转换
for (const d of diaryList) {
  if (d.images && d.images.length) {
    d.images = await toTempFileURLs(d.images)
```

- **修复方案**：改为并行：

```javascript
await Promise.all(diaryList.map(async d => {

    d.images = await toTempFileURLs(d.images)
  }
}))
```
