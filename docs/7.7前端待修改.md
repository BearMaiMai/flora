## 一、种植指南页面 — 目前仍是写死数据

### 现象
`pages/guide/index.js` 和 `pages/guide/detail.js` 的 `guideList`、`featuredGuide`、`content` 全部是硬编码 mock 数据，数据库已有真实文章但未调用后端接口。

### 后端已完成
- 云函数 `guide` 已实现，提供三个 action：

### 接口 1：获取文章列表（guide/list）

```js
wx.cloud.callFunction({
  name: 'guide',
  data: {
    action: 'list',
    page: 1,         // 页码，默认1
    pageSize: 10,    // 每页条数，默认10，最大50
    category: ''     // 可选，分类名称（中文），不传查全部
  }
})

// 返回
{
  code: 0,
  data: {
    list: [{
      _id: 'xxx',
      title: '多肉植物浇水指南',
      summary: '多肉到底多久浇一次水...',
      category: '浇水技巧',       // 中文分类名
      coverImage: 'cloud://xxx',  // 云存储 fileID
      readTime: 5,                // 阅读分钟数
      level: '入门',              // 入门/进阶/高级
      viewCount: 128,
      createdAt: '2026-06-01T...'
    }],
    total: 25,
    page: 1,
    pageSize: 10,
    hasMore: true
  }
}
```

```js
    content: '<h3>浇水原则</h3><p>见干见湿...</p>',  // HTML 格式正文

    coverImage: 'cloud://xxx',
    readTime: 5,
    level: '入门',
    viewCount: 129,
    createdAt: '2026-06-01T...',
    updatedAt: '2026-06-10T...'
  }
}
```

## 三、头像与昵称 — 前端显示/刷新问题

### 现象
- 设置页从相册选择头像后，头像不显示
- 修改昵称后返回「我的」页，昵称未更新

### 原因
1. `users.avatarUrl` 存储的是 `cloud://` fileID，`<image>` 无法直接渲染，需先用 `wx.cloud.getTempFileURL` 转成 HTTPS 临时 URL
2. `pages/profile/index.js` 的 `onShow` 只刷新 stats，未重新拉取 userInfo

### 后端状态
`user/login`、`user/getInfo`、`user/updateInfo` 均正常

### 前端需改
1. 展示头像前统一用 `utils/image.js` 的 `safeImageURL()` 转换 `cloud://` 地址
2. `pages/profile/index.js` 的 `onShow` 中调用 `userService.getInfo()` 刷新用户信息
3. `pages/profile/settings/index.js` 的 `onLoad` 直接调 `userService.getInfo()`，不要只依赖 `app.globalData`
