## 一、首页-（季节养护右侧）查看更多-种植指南页面结构（重要）

### 1.1 首页"季节养护"4个按钮的跳转逻辑

**现状**：首页有4个按钮：浇水技巧、光照管理、修剪指南、施肥方法。

**问题**：点击后跳到哪里？

**选项A**：跳转到现有"种植指南"页面，自动选中对应分类 tab（如点击"浇水技巧" → 种植指南页面选中"浇水技巧"tab）
**选项B**：每个按钮有独立的详情页，直接展示该分类下的文章列表
**选项C**：每个按钮直接展示一篇"代表作"文章，像每日小贴士一样

> 从截图看，种植指南页面已有6个分类 tab（基础、浇水技巧、光照指南、施肥方案、病虫防治、换盆教程）和文章列表。建议采用**选项A**。

## 二、植物详情页

### 2.1 养护指南文字太长

**现状**：详情页"养护指南"区域，浇水、光照等说明文字太长，前端界面显示不全（被截断为"约每维持微湿的..."）。

**后端现状**：后端返回完整文字（如 `waterDays: "见干见湿，保持土壤微湿但不要积水，夏季可适当增加浇水频率"`）。

**方案选择**：

| 方案 | 说明 | 谁改动 |
|------|------|--------|
| A | 前端做文字截断 + 点击展开/收起 | 前端 |
| B | 后端返回两个字段：`waterDaysShort`（摘要）和 `waterDays`（完整），前端默认显示短版 | 后端+前端 |
| C | 前端固定只显示前N个字，末尾加"..." | 前端 |

> **推荐方案A**，最灵活，不需要后端改数据结构。

## 三、我的—养护提醒页面

### 3.1 提醒状态颜色标识

**现状**：提醒列表页左侧有彩色圆点，但不清楚代表什么含义。

**后端期望**：

- 绿色 = 状态良好，不需要浇水
- 黄色 = 即将需要浇水（1天内）
- 红色 = 已经逾期，需要立即浇水

**后端支持**：`reminder/list` 接口会增加 `status` 字段，值为 `normal` / `warning` / `overdue`。

**需要前端确认**：

1）颜色方案是否按上述绿/黄/红？

2）是否需要在列表项右侧显示"还剩X天"或"已逾期X天"的文字？
3）把三种颜色的含义写在上方，给用户做提示

---

### 3.2 提醒列表展示信息

**现状**：列表显示"小绿（绿萝）" + 浇水图标 + "浇水"。

**建议增加信息**：
- 下次浇水日期（如"5月30日"）
- 倒计时（如"还剩2天"）
- 植物位置（如"客厅窗台"）

**后端可以返回**：`nextRemindAt`、`intervalDays`、关联 `plant` 的 `location`。

**请确认**：需要在列表中展示哪些信息？

---

### 3.3 提醒完成后的交互

**用户操作**：点击列表中的"完成"按钮。

**后端行为**：标记本次完成，并自动计算下一次提醒时间（如5天后再次提醒浇水）。

**前端交互**：完成后该条提醒是：
- 从列表中消失（跳到"已完成"tab）？
- 还是留在原地，更新为下一次提醒时间？
