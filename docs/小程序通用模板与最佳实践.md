## 2. 技术栈与目录结构

### 2.1 推荐技术栈

| 层级 | 选型 | 说明 |
|------|------|------|
| 框架 | 微信小程序原生 | 无需额外依赖，体积小 |
| 后端 | 微信云开发（云函数 + 云数据库 + 云存储） | 零运维，免费额度足够 MVP |
| 状态 | Page data + globalData + Storage | 无需 Redux/MobX |
| 样式 | WXSS + CSS 变量（Design Tokens） | 主题切换、深色模式预留 |

### 2.3 目录命名约定

- **页面**：`pages/<模块>/<页面>` (kebab-case)
- **组件**：`components/<组件名>/` (kebab-case)
- **service 文件名 = 云函数名**，方便心智映射
- **常量**：UPPER_SNAKE_CASE
- **变量/方法**：camelCase

## 4. 核心通用组件

### 4.1 必备 6 件套

| 组件 | 用途 | 关键 props |
|------|------|-----------|
| `icon` | 统一图标渲染（SVG/emoji/iconfont） | `name` `size` `color` `tint` `emoji` |
| `custom-header` | 自定义导航栏（适配胶囊） | `title` `showBack` |
| `empty-state` | 空状态 | `icon` `title` `desc` `btnText` + `bind:action` |
| `skeleton` | 骨架屏 | `type` `loading` `rows` |
| `loading` | 加载圈 | `show` `text` |
| `<biz>-card` | 业务卡片（如鱼/植物/书） | `data` `showDelete` + 事件 |

### 4.2 `empty-state` 组件契约

```html
<empty-state
  iconName="heart"          
  title="还没有收藏"
  desc="去发现你喜欢的内容吧"
  btnText="去逛逛"
  bind:action="onEmptyAction"
/>
```

> 全局注册在 `app.json` `usingComponents`，所有页面无需重复引入。

### 4.3 `icon` 组件契约

支持三种来源：
1. `<icon name="heart" />` — 内置 SVG（通过 `constants/icons.js` 映射到路径）
2. `<icon src="/path/to/x.svg" />` — 自定义路径
3. `<icon emoji="🌸" />` — emoji fallback

### 5.2 交互动画规范

| 场景 | 类名 | 时长 |
|------|------|------|
| 页面入场 | `anim-fade-in` | 0.4s |
| 卡片入场 | `anim-fade-in-up anim-delay-{{index+1}}` | 0.5s + 错峰 |
| 列表项按压 | `hover-class="hover-list-item"` `hover-stay-time="100"` | - |
| 卡片按压 | `hover-class="hover-card"` | - |
| 按钮按压 | `hover-class="hover-btn"` | - |
| 完成打勾 | `anim-check-bounce` + `wx.vibrateShort` | 0.4s |
| 点赞收藏 | `anim-heart-beat` | 0.6s |

### 5.3 hover-class 必填规则

**所有可点击元素** 必须配 `hover-class`，提供按压反馈：
- 列表项 → `hover-list-item`
- 卡片 → `hover-card`
- 按钮 → `hover-btn`
- 图标 → `hover-icon`
- 标签 → `hover-tag`

### 5.4 关键操作必振动

```js
wx.vibrateShort({ type: 'light' })   // 完成、收藏、删除等关键操作
```

## 6. 云开发后端模板

### 6.1 云函数标准模板（action 路由模式）

> **一个领域 = 一个云函数 = 一组 action**，避免云函数膨胀。

```js
// cloudfunctions/<domain>/index.js
const cloud = require('wx-server-sdk')
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })
const db = cloud.database()
const _ = db.command

exports.main = async (event, context) => {
  const { OPENID } = cloud.getWXContext()
  const { action } = event

  try {
    switch (action) {
      case 'list':    return await list(event, OPENID)
      case 'detail':  return await detail(event, OPENID)
      case 'create':  return await create(event, OPENID)
      case 'update':  return await update(event, OPENID)
      case 'delete':  return await remove(event, OPENID)
      default:
        return { success: false, code: 'UNKNOWN_ACTION', message: `未知操作 ${action}` }
    }
  } catch (err) {
    console.error(`[${action}] 失败:`, err)
    return { success: false, code: 'INTERNAL_ERROR', message: err.message }
  }
}

async function list(event, openid) {
  const { page = 1, pageSize = 20, category } = event
  const where = category ? { category } : {}
  const skip = (page - 1) * pageSize

  const [data, total] = await Promise.all([
    db.collection('xxx').where(where).skip(skip).limit(pageSize).get(),
    db.collection('xxx').where(where).count(),
  ])

  return {
    success: true,
    data: data.data,
    total: total.total,
    page,
    pageSize,
  }
}

// ...其他 action
```

### 6.2 统一返回结构

```js
// 成功
{ success: true, data: <any>, message?: string }

// 失败
{ success: false, code: 'ERROR_CODE', message: '中文错误信息' }
```

### 6.3 services 层封装

```js
// miniprogram/utils/cloud.js
async function callFunction(name, data = {}) {
  try {
    const res = await wx.cloud.callFunction({ name, data })
    if (res.result && res.result.success === false) {
      throw new Error(res.result.message || '请求失败')
    }
    return res.result
  } catch (err) {
    console.error(`[云函数 ${name}] 调用失败:`, err)
    throw err
  }
}

module.exports = { callFunction }
```

```js
// miniprogram/services/<domain>.js
const { callFunction } = require('../utils/cloud')

module.exports = {
  getList: (params) => callFunction('xxx', { action: 'list', ...params }),
  getDetail: (id)  => callFunction('xxx', { action: 'detail', id }),
  create:    (data) => callFunction('xxx', { action: 'create', ...data }),
  update:    (id, data) => callFunction('xxx', { action: 'update', id, ...data }),
  remove:    (id)  => callFunction('xxx', { action: 'delete', id }),
}
```

## 7. 数据库 Schema 模板

### 7.1 通用字段约定

每张表必含：

```js
{
  _id: String,           // 系统自动生成
  _openid: String,       // 用户私有数据自动注入
  createdAt: Date,       // 创建时间
  updatedAt: Date,       // 更新时间
  status: Number,        // 0-正常 1-删除（软删除）
}

## 8. 前后端协作约定

### 8.1 接口契约模板

每新增一个云函数 action，必须在 `docs/API接口与复用清单.md` 中登记：

```markdown
### flower.list — 获取花卉列表

**入参：**
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | Number | 否 | 默认 1 |
| pageSize | Number | 否 | 默认 20 |
| category | String | 否 | 分类过滤 |

**出参：**
\```json
{ "success": true, "data": [...], "total": 50, "page": 1 }
\```

**错误码：**
| code | 说明 |
|------|------|
| INTERNAL_ERROR | 服务器内部错误 |
```

### 8.2 字段命名

- **camelCase**（前后端统一）
- **时间字段**：`createdAt` / `updatedAt` / `nextTime`（不要用 `create_time`）
- **布尔字段**：`isXxx` / `hasXxx`（不要用 `xxxFlag`）
- **ID 字段**：MongoDB 默认 `_id`，业务 ID 用 `xxxId`

### 8.3 分支策略

| 分支 | 用途 |
|------|------|
| `main` | 生产稳定版 |
| `dev` | 集成分支（合并入口） |
| `feature/xxx` | 功能开发分支（个人） |
| `fix/xxx` | 缺陷修复分支 |

## 10. 开发规范

### 10.1 文件组织

- 单文件 ≤ 300 行，超出拆分
- 相关样式合并：`@import '/styles/animation.wxss'`
- 业务逻辑放 `services/`，**Page 不直接调用 `wx.cloud.callFunction`**

### 10.2 状态管理

```js
Page({
  data: {
    loading: true,            // 加载态（搭配骨架屏）
    list: [],
    empty: false,             // 空态
    refreshing: false,        // 下拉刷新
  },

  async onLoad() {
    const cached = getCache('xxx')
    if (cached) {
      this.setData({ ...cached, loading: false })
      this.fetchData(true)    // 后台静默刷新
    } else {
      this.fetchData()
    }
  },
})
```

### 10.3 错误处理

```js
try {
  const res = await xxxService.getList()
  this.setData({ list: res.data })
} catch (err) {
  wx.showToast({ title: '加载失败，请下拉重试', icon: 'none' })
}
