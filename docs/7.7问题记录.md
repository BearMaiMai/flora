# 7.7 前后端联调问题

## 一、退出登录无效（需前后端配合）

### 现象
点击设置页「退出登录」后，下次打开小程序自动登录，相当于退不出去。

### 原因
微信小程序的 `openid` 绑死微信号，不存在传统意义的"退出登录"。当前前端只清了本地缓存，下次进页面自动调 `silentLogin()` 又绑回同一用户。

### 后端已完成
- `user/login` 新增返回 `sessionToken`
- `user/logout` 新增，清除用户 `sessionToken`
- `user/index.js` 已注册 `logout` 路由

### 前端需改
1. 退出登录时调后端 + 清本地：
```js
wx.cloud.callFunction({ name: 'user', data: { action: 'logout' } })
wx.removeStorageSync('userInfo')
wx.removeStorageSync('sessionToken')
wx.setStorageSync('loggedOut', true)
wx.navigateTo({ url: '/pages/index/index' })
```

2. App 启动时检查：
```js
if (wx.getStorageSync('loggedOut')) return
userService.login()
```

3. 用户再次点击登录时，清除 `loggedOut` 标志，调 `userService.login()`
